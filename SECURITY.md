# Security Policy

## Workspace Isolation

Hydrogen Team executes agent-authored scripts and FFmpeg commands inside per-run workspace directories (`runs/<run_id>/workspace/`). All file read/write tools enforce canonical path validation (`RunWorkspace.resolve_safe_path`) to prevent path traversal outside the active run directory.

Because `run_python_script` executes Python code generated by AI agents on the host environment, you should run Hydrogen Team inside a container (`Dockerfile` provided) when exposing the web UI to untrusted users or untrusted prompts.

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public issue. Instead, report it privately to the maintainers with reproduction steps and impact details so we can coordinate a fix responsibly.
